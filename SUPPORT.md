## 2. Community Channels

### GitHub Discussions
For general questions, architecture discussions, ideas, and sharing your deployment patterns:
- Join the conversation on [GitHub Discussions](https://github.com/anwar/OpsPilot/discussions).
- Search previous discussions before opening a new thread.

### GitHub Issues (Bugs & Feature Requests)
- **Bug Reports:** If you discover a reproducible defect in the platform, open an issue using the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature Requests:** To propose an architectural enhancement or integration adapter, use the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).

---

## 3. Security Inquiries

For sensitive security disclosures, do not open public GitHub issues. Follow the confidential disclosure procedure outlined in [SECURITY.md](SECURITY.md).

---

## 4. Professional & Commercial Support

OpsPilot is currently developed as an open-source project. If your engineering team is evaluating OpsPilot for mission-critical deployments and requires custom integration guidance, architectural review, or dedicated support, please reach out to the project maintainers via the contact details in the repository profile.
